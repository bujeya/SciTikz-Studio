# SciTikZ Studio v5.0 Pro

SciTikZ Studio is an interactive web-based scientific setup tool that allows visual drawing of laboratory and circuit components with real-time export to LaTeX/TikZ and CircuiTikZ code.

## 🚀 Live Demo (GitHub Pages)
Host directly on GitHub Pages with zero server setup!

## 📦 Features
- **Chemistry**: Glassware, Reflux Condensers, Titration Burettes, pH Meters, Gas Syringes.
- **Optics**: Lasers, Polarizers, Waveplates, Beam Splitters, Prisms, Lenses & Mirrors.
- **Electronics**: Resistors, Capacitors, MOSFETs, 555 Timer ICs, Logic Gates (AND, OR, XOR, NOT).
- **Tools**: Dynamic Dimension Ruler (auto-calculated lengths in cm), LaTeX Math Formatting.
- **Export**: Instant Copy TikZ, Download `.tex` files, Vector Canvas.

## 🛠 Deployment on GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** -> **Pages**.
3. Select `Branch: main` and `/ (root)`.
4. Click **Save**. Your app will be live at `https://<your-username>.github.io/<repo-name>/`.
